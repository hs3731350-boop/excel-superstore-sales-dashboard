# Excel Superstore Sales Dashboard

## Overview
An interactive sales performance dashboard built in Excel to analyze sales, profit and discounts using the Superstore dataset.

## Business Problem
Which regions, categories and customer segments drive sales and profit, and where do discounts hurt profitability?

## Dataset
Superstore dataset, 9,994 rows and 21 columns (Sales, Quantity, Discount, Profit, Region, Category, Segment, dates).

## Tools Used
Excel, Power Query, PivotTables, Slicers, XLOOKUP, SUMIFS
